## Полный перенос на чистую RED OS ВМ

6 октября 2026 года выполнен перенос из тестового `officechattest` на отдельный
`regenerationofficechat` (`192.168.0.222`, RED OS 8.0.3 Standard Server Minimal).
Новый origin — `https://regenerationofficechat.adm.net`. SELinux оставался
Enforcing; исходный сервер продолжал работу.

- Чистый installer RC13.36 завершился успешно с `--no-create-admin`.
  Таймер назначения намеренно остался disabled/inactive. Первоначальный отказ
  проверки был ошибкой проверочного блока при ожидаемом ненулевом коде
  `systemctl is-enabled`; повторная проверка исправленного блока прошла.
- Копия `officechat-backup-20261006-102608Z` создана на источнике и проверена
  локально и на SMB `//192.168.1.100/backup_share/OfficeChatRedRc36`.
- Новый сервер подключил ресурс в `/mnt/officechat-restore-source` с `ro`.
  `verify-backup` и изолированный drill прошли: 35 tables, 35 relations,
  одно extension, Alembic `20260728_0026`, PostgreSQL 16.15 с обеих сторон.
- Локальные `deployment-private.tar.gz`, `caddy-ca.tar.gz` и публичный root.crt
  переданы отдельно по SSH; SHA-256 файлов на назначении совпали.
- В `.env` назначения перенесён только `APP_SECRET_KEY` источника;
  остальные строки, включая пароль PostgreSQL и новые HTTPS URL, сохранены.
- `restore-production.sh --production` восстановил рабочую БД и uploads,
  оставил предвосстановительную копию `officechat-backup-20261006-104204Z`,
  database `officechat_rollback_20261006104224_44947` и uploads
  `/var/lib/officechat/uploads.rollback-20261006104224_44947`. Восстановлен один
  пользователь; миграции, readiness и `officechatctl health` прошли.
- PKI Caddy восстановлен из исходного архива в `/data/caddy/pki`, сертификат
  нового имени перевыпущен. Предыдущее состояние сохранено в
  `/root/officechat-ca-before-restore.ETQHV6`. SHA-256 экспортированного root.crt
  совпала с источником:
  `675412ab5cbc3a9364caa3b6fa5e63ab69ce7044d0ee568b3b0c43372da1b7cc`.
  HTTPS `/ready` ответил `200` с `curl --cacert` и новым hostname, без `-k`.
- Оператор подтвердил успешную работу. Скриншот нового origin показывает вход
  под `admin`/superadmin, `TestGroup`, сообщение
  «Проверка переноса RC13.36 — 06.10.2026», карточки
  `test-regenerationofficechat.txt` (38 байт) и старого
  `test-files-officechat-redos (2).txt` (894 байта), онлайн-обновления подключены.

Зафиксированы успешные маркеры `REDOS_RC13_36_CLEAN_INSTALL`,
`RESTORE_SOURCE`, `TARGET_RESTORE_DRILL`, `PRIVATE_TRANSFER`, `TARGET_RESTORE`
и `SOURCE_CA_RESTORE`; соответствующие предоставленные exit codes равны 0.
Приватные архивы и значения секретов в репозиторий не включены.

Пошаговая процедура с проверками hostname, переносом приватных архивов,
selective `.env` и восстановлением правильного формата PKI:
[перенос на новый сервер](../deployment/restore-to-new-server_RU.md).

Граница этого результата: reboot нового сервера после переноса ещё не выполнен.
На скриншоте Chrome показывал «Не защищено»; клиентское доверие Windows/браузера
нужно проверить отдельно, несмотря на успешную серверную проверку CA.
Отдельный хеш скачанного вложения и новое сообщение после переноса не
зафиксированы. Собственная backup-площадка назначения не настроена.

## Оставшаяся приёмка

Следующие сценарии ещё не имеют полного набора результатов:

- NFS на Debian и RED OS, включая переход SMB/NFS.
- После выполненного переноса на чистую RED OS ВМ: reboot, клиентское доверие
  сертификату без предупреждения, хеш скачанного вложения и запись нового
  сообщения. Отдельная полная проверка переноса на чистую Debian ВМ не проведена.
- Прерывание исполнителя и перезагрузка именно во время смены площадки.
- Недоступность старого NAS во время отката, повторное восстановление журнала,
  смена SMB-сервера и учётной записи.
- Проверка итогового коммита после объединения в `main` и его релизной упаковки.

Список процедур остаётся в [руководстве по хранилищу и расписанию](../deployment/backup-destinations-schedule-ru.md).
Подтверждённые проверки выполнялись на малом тестовом наборе данных;
нагрузка, объём копий и ёмкость для 300 активных пользователей не измерялись.
