## Простая установка

Существующая точка входа — `officechat-install.sh` из GitHub Release
(исходник `scripts/release/bootstrap-linux.sh`). Он скачивает и проверяет bundle,
устанавливает Docker/Compose на поддерживаемой ОС, запрашивает пароль первого
администратора, запускает приложение и Caddy и сохраняет корневой сертификат.
Подробности и поддерживаемые ОС: [INSTALL_RU.md](../INSTALL_RU.md).

Для пилота нужен минимальный путь: DNS-имя → скачать installer и checksum →
проверить checksum → запустить с точной версией и hostname → доверить CA на
клиентах → войти. Затем настроить NAS, расписание и проверить восстановление.

Текущие GHCR-образы приватные: требуется GitHub account с доступом и
авторизация Docker с read:packages. На чистой VM installer сначала устанавливает
Docker, затем останавливается до login; после login его запускают повторно.
Это ограничение текущей «простой установки» должно быть явно указано. Изменение
видимости packages не выполняется в рамках исправления сокета.

Не использовать `latest` или команду для ещё не опубликованной версии.
Тесты скриптов с подменёнными системными командами не заменяют чистую VM.
