## Debian: приёмка интерфейса и прав

| Учётная запись | Выданные права | Проверенный результат |
| --- | --- | --- |
| admin | Все права; UI показывает superadmin | Создание, применение и редактирование собственных шаблонов; для шаблона TestUser 1 только «Использовать» |
| TestUser 1 | Массовая рассылка | Использование шаблонов admin без изменения/удаления; создание и редактирование собственного; удаление отдельного своего шаблона после повторного входа |
| TestUser 2 | Календарь, справочник, закрепление сообщений | Нет формы создания объявлений/шаблонов; получает объявление, адресованное TestGroup |
| TestUser 3 | Обычный пользователь | Нет формы создания объявлений/шаблонов; не получает объявление для TestGroup |

TestUser 1 и TestUser 2 состоят в TestGroup, TestUser 3 не состоит. Оператор
подтвердил сохранение, применение и отправку шаблонов и сохранение прав после
повторного входа. На скриншотах видны центрированный заголовок, полужирный,
курсив, подчёркивание и маркированный список.

Проверка аудитории повторена через «Объявления» → «Новая рассылка» →
«Выбранные группы» → только TestGroup → «Проверить получателей» →
«Отправить рассылку». Оператор подтвердил правильное оформление у TestUser 2
и отсутствие этой рассылки у TestUser 3. Обычное сообщение в чате группы
не считалось подтверждением проверки массовых объявлений.

Ручная приёмка проверяет UI; серверные отказы чужому автору, включая admin/
superadmin, проверены HTTP-тестами в CI. Эти тесты используют подменённую
сессию БД и не являются отдельной ручной атакой на production API.
